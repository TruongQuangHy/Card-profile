# Frontend Aesthetics & High-Craft Motion Rules (Anti-Slop & Emil Kowalski Standard)

## 1. Core Principles
- **No Generic AI Slop**: Banned: generic purple/cyan gradient cards, identical 3-column repetitive boxes, scale(0) popups, meaningless decorative badges, unmotivated icons.
- **Emil Kowalski Micro-Interactions**:
  - Tactile Press: Every interactive button/card MUST have an explicit `:active` or `whileTap={{ scale: 0.97 }}` state.
  - Real-world Entrances: NEVER animate from `scale(0)`. Elements enter from `scale(0.96)` and `opacity: 0` with quick, confident spring physics or `cubic-bezier(0.16, 1, 0.3, 1)`.
  - Velocity & Timing: Interactive UI transitions must resolve in ≤ 200ms. Never use `transition: all 300ms`; specify exact animated properties (`transform`, `opacity`, `background-color`).
  - Spatial Consistency: Dialogs and drawers exit in the direction they entered.
- **Anti-Slop Layout & Typographic Mastery**:
  - Asymmetric Bento Grid: Feature hero pieces with distinct aspect ratios, live micro-apps, and full substance.
  - Bold Editorial Hierarchy: Big, confident headline typography contrasting with ultra-sharp, technical monospace meta-tags.
  - Deep Black Luxury: Ground backgrounds in Obsidian / Slate-950 (`#05070c`), using subtle layered glass, crisp 1px borders (`rgba(255, 255, 255, 0.08)`), and restrained, purposeful glow highlights.
- **Kinetic Smooth Scroll**:
  - Integrate Lenis smooth kinetic scroll to provide premium desktop momentum.
- **Real Substance Over Placeholder Clutter**:
  - Display actual engineering metrics, real project screenshots, working terminal commands, and authentic interactive previews.
