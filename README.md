# 🌟 Trương Quang Hy — Senior Front-End & Full-Stack Engineer Portfolio & CV

A modern, high-performance, and interactive Developer Portfolio & CV Website built with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4**, **Framer Motion**, and **Web Audio API**.

---

## 🚀 Key Highlights & Features

1. **Bento Grid Architecture & Dark-First Aesthetic**:
   - Modern glassmorphism, dynamic spotlight hovering effects, glowing mesh grid, and cybernetic accents.
   - Dual-language support: **Tiếng Việt 🇻🇳 / English 🇬🇧** with instant state switching and `localStorage` persistence.
   - System/User theme conformance with zero Flash of Unstyled Content (FOUC).

2. **Full Showcase of 7 Production Systems**:
   - **TBChat Web (Official Chat Web)**: Enterprise P2P & Realtime Messenger with WebRTC, SSE, GSAP, Lenis Smooth Scroll, and SQLite/IndexedDB caching.
   - **Nexsoft Admin Web**: Financial SaaS administration portal with Next.js, TanStack Query v5, TanStack Table v8, Framer Motion, and Lingui i18n.
   - **Cloud Drive Web**: High-performance cloud workspace with TanStack Vue Virtual for 50,000+ files and granular privacy control.
   - **HyFlim**: Fullstack Movie Streaming platform with adaptive HLS video streaming, Supabase, and companion React Native Expo mobile app (`HyFlim.apk`).
   - **Mogu**: AI Smart Meal Planner monorepo with NestJS Fastify, Prisma, Redis BullMQ queues, HuggingFace NLP, and React Native Expo 57 mobile app (`mogu-release.apk`).
   - **Talio**: AI-Powered Talent Matching Platform & CV Builder with DISC/EQ evaluations, pgvector semantic search, and AWS S3 storage.
   - **XEPO Ecosystem**: Digital identity and workflow orchestration monorepo with Capacitor native iOS & Android integration.

3. **Interactive Components**:
   - **Case Study Deep Dive Modal**: Technical challenges, engineered solutions, architecture highlights, metrics, and repository/demo links.
   - **Retro-Modern CLI Terminal (`Ctrl+K`)**: Interactive command palette with commands like `help`, `skills`, `projects`, `contact`, `hire`, `cv`, `clear`.
   - **Full Curriculum Vitae (CV) Modal**: Print-optimized CV layout with instant PDF download (`window.print()`).
   - **Zero-Dependency Synthesized Audio FX**: Futuristic micro-interaction audio feedback (clicks, chirps, fanfare) synthesized purely using the native browser Web Audio API (with mute toggle).
   - **Live Indochina Time (ICT, GMT+7) Clock**: Real-time timezone sync for international recruiters and clients.
   - **Direct Contact Form**: One-click email copy with toast notification and interactive message sender.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5.x (App Router, Turbopack ready, React Server Components)
- **Library**: React 19.3.x
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Sound Effects**: Native Web Audio API Synthesizer
- **Celebration Effects**: Canvas Confetti
- **Language**: TypeScript 5.9+

## 💻 Getting Started

### 1. Install Dependencies

```bash
pnpm install
# or: npm install
```

### 2. Run Development Server

```bash
pnpm dev
# or: npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the portfolio.

### 3. Build for Production

```bash
pnpm build
pnpm start
```
